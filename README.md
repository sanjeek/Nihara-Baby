# Baby’s Big Adventure

A cozy, playable 3D browser prototype built with Three.js and Vite. Explore a miniature nursery, collect three stars, and jump onto the pink cushion to reach Teddy.

## Run

Requires Node.js 20.19+ or 22.12+.

```sh
npm ci
npm run dev -- --port 5173
```

Move with WASD or arrow keys; jump with Space. Phones and tablets have directional buttons and a jump button. Use the restart button to reset the adventure. The living room and garden are future chapters; the nursery is the playable level.

```sh
npm run build
npm run preview
```

All 3D objects are generated locally. No external assets, API keys, backend, or accounts are required. This is a stylized prototype, not a reproduction of the detail in the concept art. GitHub repository creation and deployment are separate from this local build.
